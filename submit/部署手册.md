# BOSS求聘部署手册

## 1. 服务组成

- API：FastAPI，端口 8000
- 前端：Streamlit，端口 8501
- 数据：data/processed/jobs_cleaned.parquet
- RAG：本地 FAISS/BGE 索引；索引或模型不可用时 API 返回错误，不回退到 TF-IDF

## 2. 本地 Python 启动

在项目根目录执行：

    ./scripts/python.sh -m app.run_api
    ./scripts/python.sh -m app.run_frontend

访问：

- 前端：http://127.0.0.1:8501
- API 文档：http://127.0.0.1:8000/docs
- 健康检查：http://127.0.0.1:8000/api/health

## 3. Docker Compose 启动

标准环境可执行：

    docker compose build
    docker compose up -d

如 Docker Hub 拉取 `python:3.12-slim` 出现网络超时，可先将本机已验证的 API 镜像标记为构建基底：

    docker tag boss-qiupin-api:week3 boss-qiupin-api:week3-base
    docker build --build-arg BASE_IMAGE=boss-qiupin-api:week3-base -t boss-qiupin-api:week3 .
    docker compose up -d

该处理只用于本机断续网络环境，Dockerfile 默认基础镜像仍是 `python:3.12-slim`。

## 4. 启停与检查

    docker compose ps
    docker compose logs --tail=100 api
    docker compose logs --tail=100 frontend
    curl http://127.0.0.1:8000/api/health

停止服务：

    docker compose down

本地容器验证结果：api healthcheck 为 healthy，`/api/health` 返回 12,000 条岗位数据，前端 8501 返回 HTTP 200。`/api/retrieve` 使用 `faiss_bge_embedding`，`/api/chat` 已用 `gpt-5.6-sol` 和 Responses Function Calling 完成真实工具调用。

## 5. 环境变量

- API_URL：前端调用 API 的地址，Compose 中为 http://api:8000
- FRONTEND_API_TIMEOUT：前端普通 API 请求超时，默认 180 秒
- FRONTEND_REAL_AGENT_TIMEOUT：真实 Agent 请求超时，默认 150 秒
- AGENT_MODEL：默认 `gpt-5.6-sol`
- OPENAI_BASE_URL：自定义 OpenAI-compatible 网关地址
- AGENT_PROTOCOL：默认 `responses`
- OPENAI_API_KEY：仅通过主机或 Render Secret 环境变量注入，不写入项目文件

## 6. Render 部署准备

- 仓库已提供 `render.yaml`，包含 API 与前端两个 Web Service。
- 正式 FAISS 索引和 BGE 模型快照已发布为 GitHub Release 资产，约 206 MB。
- API Dockerfile 会下载该资产、校验固定 SHA-256，并检查索引、Chunk 元数据和 `model.safetensors` 是否存在。
- 在 Render 控制台仅需手动配置 `OPENAI_API_KEY` Secret；密钥不得写入仓库。
- 前端通过 `API_URL` 连接 API 服务。若 Render 实际分配的 API 域名不同，应同步修改该环境变量。

## 7. 临时公网演示

2026 年 9 月 20 日已通过 Cloudflare Quick Tunnel 暴露前端 8501 端口，答辩临时公网地址为：

    https://mesa-clip-weight-fleece.trycloudflare.com

该地址已实测 HTTP 200。它映射到本机 Docker 前端服务，不是永久云服务器托管；演示期间需要保持 Docker Compose 和 `tmp/cloudflared/cloudflared` 隧道进程运行。若隧道进程停止，地址会立即失效。本地备用地址仍为 `http://127.0.0.1:8501`。

## 8. 部署边界

Render 配置、Dockerfile 以及 GitHub Release 中的 FAISS+BGE 构建资产均已准备，但本次交付采用临时公网演示，不把 Render 未发布状态写成已完成的永久云部署。
