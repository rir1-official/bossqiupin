# BOSS求聘部署手册

## 1. 服务组成

- API：FastAPI，端口 8000
- 前端：Streamlit，端口 8501
- 数据：data/processed/jobs_cleaned.parquet
- RAG：本地 FAISS/BGE 索引；索引或模型不可用时 API 返回错误，不回退到 TF-IDF

## 2. 本地 Python 启动

在项目根目录执行：

    ./scripts/python.sh -m app.run_api
    ./scripts/python.sh -m app.run_frontend

访问：

- 前端：http://127.0.0.1:8501
- API 文档：http://127.0.0.1:8000/docs
- 健康检查：http://127.0.0.1:8000/api/health

## 3. Docker Compose 启动

标准环境可执行：

    docker compose -p bossqiupin build
    docker compose -p bossqiupin up -d

本地验证时，因 Docker Hub 拉取 python:3.12-slim 出现网络超时，使用本机已有镜像作为临时基础镜像：

    docker compose -p bossqiupin build --build-arg BASE_IMAGE=moodtune-pyspark:3.5.3
    docker compose -p bossqiupin up -d

该替代参数只用于本机 ARM64 验证，Dockerfile 默认基础镜像仍是 python:3.12-slim。

## 4. 启停与检查

    docker compose -p bossqiupin ps
    docker compose -p bossqiupin logs --tail=100 api
    docker compose -p bossqiupin logs --tail=100 frontend
    curl http://127.0.0.1:8000/api/health

停止服务：

    docker compose -p bossqiupin down

本地容器验证结果：api healthcheck 为 healthy，/api/health 返回 12,000 条岗位数据，前端 8501 返回 HTTP 200。

## 5. 环境变量

- API_URL：前端调用 API 的地址，Compose 中为 http://api:8000
- FRONTEND_API_TIMEOUT：前端普通 API 请求超时，默认 180 秒
- FRONTEND_REAL_AGENT_TIMEOUT：真实 Agent 请求超时，默认 150 秒
- OPENAI_API_KEY 或已有 OpenAI-compatible 运行时配置：仅用于真实 Agent 调用，不写入项目文件

当前已完成本地 Python 联调和本地 Docker 容器验证。尚未完成云服务器部署，因此暂不提供在线演示地址。现场演示应使用本机地址，并提前完成一次真实 Agent 调用以减少外部网络波动影响。
